# Memoria Viva — web estática

Web responsive para presentar actividades personalizadas de envejecimiento activo a domicilio, recibir consultas y solicitar cita por WhatsApp.

## Tecnología
- HTML, CSS y JavaScript nativos.
- Sin framework, backend, base de datos, analítica ni formularios.
- Preparada para GitHub Pages desde la raíz del repositorio.
- Diseño adaptable a móvil y navegación accesible básica.

## Antes de publicar comercialmente
1. Completar los datos legales pendientes en `privacidad.html` y `aviso-legal.html`.
2. Confirmar el nombre comercial y la disponibilidad de marca.
3. Confirmar con el Colegio Oficial de la Psicología de Las Palmas y la autoridad sanitaria el alcance legal de los servicios anunciados.
4. No anunciar diagnósticos ni tratamientos sanitarios sin habilitación y autorizaciones aplicables.
5. Revisar que los textos comerciales reflejan los servicios reales y añadir cualquier información de contacto necesaria.

## Activar GitHub Pages
1. En GitHub, abrir **Settings → Pages**.
2. En **Build and deployment**, elegir **Deploy from a branch**.
3. Seleccionar la rama `main` y la carpeta `/ (root)`.
4. Guardar y esperar a que GitHub muestre la URL publicada.
5. Comprobar la web y los botones de WhatsApp en móvil.

## WhatsApp y citas
Los botones abren WhatsApp con un mensaje preescrito. La cita se coordina manualmente; no existe calendario ni reserva automática. No pedir datos médicos ni información sensible en el primer contacto.

## Privacidad
La web no incorpora formularios, analítica ni almacenamiento local de datos personales. Al abrir WhatsApp, la persona pasa a un servicio externo. Las páginas legales son borradores y deben completarse y revisarse antes de publicar como sitio comercial definitivo.
